- **"After every merge" was too broad.** `sandbox.yml` runs after merges that touch the examples or the wrapper, not after every merge. The sentence was corrected before committing.

- **Links to `piece-01-v1` don't work yet.** The tag is created when the code is frozen for publication (PUBLISHING.md, step 1). Until then the article's code links return 404. That's deliberate, so the article never points at a branch that can move.
