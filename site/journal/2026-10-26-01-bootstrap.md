## Dead ends and surprises

- **The GitHub `.gitignore` template ignored `/site`.** The Python template that GitHub added in the initial commit contains `/site` (for mkdocs), which would have silently dropped the whole making-of site from git. Removed, with a comment explaining why.
- **KVM is there but out of reach.** `/dev/kvm` exists in the Codespace, but it belongs to GID 109, a group with no name in `/etc/group`, and the `codespace` user isn't a member. `sbx diagnose` says *Virtualization — not accessible*. CLAUDE.md forbids privileged workarounds, so nothing was changed. The documented fix is to add the user to the device's group, and whether that's acceptable is a question for the author.
- **`sbx` v0.50.0 was a few hours old.** It was released on 2026-10-26 at 14:44 UTC; CLAUDE.md §5.1 had been checked against the v0.49.2 era five days earlier. That's the release cadence §0.4 warns about.
- **A command the release notes announce isn't in the help index.** `sbx --cloud inspect` is announced in the v0.50.0 notes and works, but `sbx --help` doesn't list it.
- **The docs' "append `.md`" rule has an exception.** The install page is linked as `/ai/sandboxes/get-started/install/`, but its raw Markdown lives at `/ai/sandboxes/install.md`.
- **mermaid-cli 12 changed its flags.** `-w` (width) is gone, replaced by `--size`. The first `make diagrams` failed on a flag written from memory: the same failure mode §0.4 guards against for `sbx`, in a different tool.
- **Headless Chrome needed one system library** (`libasound2t64`) to render diagrams. `post-create.sh` now installs Chrome's full library list for a bare devcontainer image.
- **The first two layouts of the workflow diagram tangled the edges.** Modelling the sandbox round trip as one two-way edge fixed it.
