## Dead ends and surprises

- **A sentence that would have been false.** An early wording said the report was identical "on my machine" and in the cloud. The host is a Codespace, not the author's laptop, so it now says "in my Codespace". The same check applies throughout: the hub must not imply a local-sandbox run that hasn't happened (ADR-0010).
- **"Every sentence is mine" contradicted the disclosure line.** The hub is drafted with Claude, so the source note now says the sentences are paraphrases and doesn't claim authorship of every word.
- **shellcheck found two real bugs on its first run:**
  - `site-check.sh` didn't stop when `cd` failed, so it would have checked the wrong directory.
  - `sbx-run.sh` used an unquoted variable inside a pattern expansion.

  Its two other findings were false positives, now documented in the code.
- **Docker doesn't publish cloud-sandbox rates in its docs.** The docs say how compute is billed: by the second, on runtime times the CPU/memory shape, with no subscription fee and a one-time promotional credit at signup. The rates themselves appear only in the Agentic Platform Console. So the CI-cost answer gives the measured usage (10–17 s of the smallest shape per run of piece 01), and the author reads the price.
- **Feynman's book has two publication years:** catalogs say 1995, some 1994. The hub says "mid-1990s" rather than pick one.
- **Two pull requests in flight.** The author merges PR #3 while this session works. The hub draft therefore stays local until the merge, so #3 contains exactly what was reviewed.
