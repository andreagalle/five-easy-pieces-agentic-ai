## Dead ends and surprises

- **A broken link in Docker's own docs.** The credentials page points to `/ai/sandboxes/configuration/security/`, which returns 404. The security model lives at `/ai/sandboxes/security/`. Checking every link before putting it in the article is what found it. Recorded in `references/sbx-notes.md`.
- **Renaming a folder with git-ignored files in it.** `git mv` would have moved only the tracked files and left the PNG master and the drafts behind. Moving the folder and then letting git detect the rename kept everything together.
- **A missed "hub".** The first search-and-replace pass missed one inside a longer sentence of the illustrations README. A second, word-level search found it.
